\# Freshservice Issue Tracking Process



Freshservice was used to track features and security issues during the project.



1\. A ticket was created with a subject and description.

2\. The ticket was assigned to the Network Team and an agent.

3\. The status was changed from Open to Pending while the work was being completed.

4\. Git commits referenced the Freshservice ticket number.

5\. The GitHub Pull Request link and test result were added to the ticket.

6\. The ticket was changed to Resolved after the work was tested and merged.



Two tickets were used:



\- INC-1: Implement log analysis script

\- INC-2: Fix insecure system configuration
