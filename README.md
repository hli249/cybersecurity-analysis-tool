\# Cybersecurity Analysis Tool



This project contains simple tools for log analysis and vulnerability assessment.



\## Project Files



\- log\_analysis.py: Checks log files for possible security incidents.

\- sample.log: Contains sample log entries for testing.

\- vulnerability\_assessment.py: Checks security configuration settings.

\- system\_config.txt: Contains the tested configuration.

\- vulnerability\_report.md: Documents the vulnerabilities and fixes.



\## Requirements



\- Python 3

\- Git



\## How to Run



Run the log analysis tool:



py log\_analysis.py



Run the vulnerability assessment tool:



py vulnerability\_assessment.py



\## Branches



\- main: Production branch

\- development: Ongoing development

\- feature/log-analysis: Log analysis development

\- feature/vulnerability-assessment: Vulnerability assessment development



\## Security Procedures



Test data should not contain real passwords or private information. Any vulnerability found should be documented, fixed, and tested again before the change is merged.
